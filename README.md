# 💘 Meus Sites Favoritos

## 🎯 Objetivo do programa

🏹 Desenvolver uma página web com sites favoritos utilizando a linguagem de marcação HTML;

🏹 O uso de tags e atributos que favoreça a renderização o código na web;

🏹 Hospedar link executável do site no Github Pages.

## 💻 Sintaxe do código

    👩‍💻 O título da página web (aba) é: Meus sites favoritos.
    
    👩‍💻 O título do corpo da página é: Meus sites favoritos seguido do nome do autor.

    👩‍💻 O corpo da página ilustra imagens de sites frequentemente acessados.

    👩‍💻 O link de cada site está inserido abaixo da imagens correspondente.

## ⚙️ Instruções da execução do programa

    🔧 A página web exibe links para sites frequentemente acessados.
