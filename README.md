# 💘 Meus Sites Favoritos

## 🎯 Objetivo do programa

🏹 Desenvolver uma página web com sites favoritos utilizando a linguagem de marcação HTML;

🏹 O uso de tags e atributos que favoreça a renderização o código na web;

🏹 Hospedar link executável do site no Github Pages.
